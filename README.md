📊 Sales Analytics Dashboard – Power BI

📌 Project Overview

This project focuses on analyzing sales data using Microsoft Power BI to gain insights into sales performance, customer orders, product categories, profitability, and sales trends.

The dashboard provides a visual representation of key business metrics, helping users understand sales performance across different categories, locations, and time periods.

⸻

🛠️ Tools & Technologies Used

* Microsoft Power BI Desktop – Data visualization and dashboard creation
* Microsoft Excel – Data source and initial data handling
* Power Query – Data cleaning, transformation, and preparation
* Data Modeling – Relationships between tables
* DAX – Calculations and measures for KPI analysis

⸻

🎯 Project Objectives

* Analyze overall sales performance
* Track total revenue and number of orders
* Understand profitability through average profit
* Compare sales across different product categories
* Analyze sales trends over time
* Identify top-performing locations based on sales
* Compare sales performance across different years

⸻

📈 Dashboard Features

The dashboard includes the following key visualizations:

🔹 Key Performance Indicators (KPIs)

* Total Revenue
* Total Orders
* Average Profit

🔹 Sales by Category

A comparison of sales performance across different product categories:

* Clothing
* Electronics
* Furniture

🔹 Sales Trend by Year

Visualizes sales performance across different years to identify trends and changes in revenue.

🔹 Top 10 Locations by Sales

Highlights the top 10 locations contributing the highest sales.

🔹 Year Filter

An interactive slicer that allows users to filter the dashboard by year.

⸻

🧹 Data Preparation

The data was prepared and transformed using Power Query in Power BI.

The data preparation process included:

* Reviewing the datasets and their structure
* Checking and correcting data types
* Cleaning and preparing data for analysis
* Handling data inconsistencies where required
* Creating aggregated tables for analysis
* Preparing data for visualization
